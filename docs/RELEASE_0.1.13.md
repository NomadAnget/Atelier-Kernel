# Atelier Kernel 0.1.13

- 大存储结果与非观察消息积压超过内存窗口时，由内核自动临时暂存并按序发送，不再因为2MiB出口门槛关闭业务域。SDK调用方式不变。
- 临时传输文件仅属于当前进程代际，写完、排空或关闭后回收；不写持久投递账本，不跨重启重放。观察事件仍允许丢失。单帧编解码内存仍与帧大小相关。
- 明确进程回收期间的PID所有权，完成回收后才移除身份；支持独立域环境变量覆盖。
- 增加进程退出和IPC故障诊断，保留首个故障证据。
- Python/Node SDK同步支持显式进度完成、失败状态。

验证：Rust全量回归、11项跨语言SDK脚本；真实子进程连续两次查询12MiB检查点且不换代。用户已确认本地任务重跑通过。

旧测试中要求非持久积压必须导致域退出的两项断言，已按此次修复目标替换为完整交付、非持久账本、保持进程与其他域响应的断言，未跳过测试。
