# 大存储结果与出口积压

原实现把2MiB/1024条内存窗口当作连接失败条件，导致正常检查点查询关闭域。现在非观察帧溢出时写入代际私有 SQLite 临时数据库，按通道顺序发送，物理写入确认后删除；排空或关闭代际时关闭并删除临时数据库。不会写入持久投递账本，也不恢复或重放临时帧。观察事件仍按原有可丢失策略处理。

回归覆盖12MiB单帧、1500条积压、顺序、临时库回收、真实子进程连续两次12MiB存储查询、慢进程保持代际及其他域可响应。原有两项测试要求容量超限必须杀域，与此次修复目标冲突，已改为验证完整交付、非持久账本语义及进程存活，未跳过测试。

限制：单帧JSON编解码仍按帧大小占内存；本次修复不是流式JSON编解码。临时文件真实读写故障仍需明确故障处理，不保证磁盘无限容量。
