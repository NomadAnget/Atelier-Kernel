# Atelier Kernel 0.1.14

- 新增启动配置`ports`绑定：内核自动维护独立薄TCP转发进程，公开端口与域代际解耦；Python/Node SDK通过`domain.bindings`取得内部端点，在启动回调成功后报告应用启动完成。
- 滚动更新在注册及端口启动握手完成后切换后端，候选失败保留旧实例；旧连接最多排空30秒。端口绑定变更需要另行迁移，SSE/WebSocket可能需要重连；不承诺任意业务请求无损迁移。
- 文件装配的UpdateDomain未传spec时重新读取并校验启动文件，失败不静默使用旧配置。显式spec优先，嵌入式无文件来源沿用内存规格。
- 域真实状态变化加入原观察流，订阅自动提供完整状态镜像；内核和双SDK合并慢观察者的最新镜像，不增加轮询或公开队列参数。普通生命周期事件仍为可丢失副本，不建立持久事件系统。
- 修复状态扇出与域注册之间的锁顺序，保护状态镜像的同时保持原观察队列字节预算，补充跨语言真实进程、停止、崩溃恢复、重订阅和慢消费回归。
- 同步架构、SDK、变体指南与观察使用文档，历史审计明确标注对应旧基线；修正专用IPC、更新返回结构及未实现probe_handler的说明。

本地验证：126项Rust测试通过（4项专用子进程夹具由父测试调用，不计普通通过），11项SDK脚本通过，Release构建及Windows GNU交叉检查通过；没有放宽既有观察队列预算断言。云端原生三平台验证以本版本工作流实际结果为准。发布包包含同版本Python wheel、Node tgz及Linux x86_64、Windows x86_64、macOS arm64运行包。
